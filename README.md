# 🎂 Simple Age Calculator

## 📌 Project Overview
The **Simple Age Calculator** is a beginner-friendly web application that calculates a person's age based on their date of birth. Users can enter their date of birth and instantly find their age in years, months, and days.

This project demonstrates basic JavaScript functionality, DOM manipulation, and date calculations.

## 🚀 Features
- Enter your date of birth.
- Calculate age accurately.
- Display age in years, months, and days.
- Simple and user-friendly interface.
- Instant results.
- Input validation to prevent invalid dates.
- Responsive design for different screen sizes.

## 🛠️ Technologies Used
- **HTML5** – Structure of the application.
- **CSS3** – Styling and responsive design.
- **JavaScript** – Age calculation logic and DOM manipulation.

## ⚙️ How to Run the Project

1. Clone this repository:

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
```

2. Open the project folder in VS Code.
3. Open `index.html` in your browser.
4. Select your date of birth.
5. Click the Calculate button.
6. View your calculated age.
